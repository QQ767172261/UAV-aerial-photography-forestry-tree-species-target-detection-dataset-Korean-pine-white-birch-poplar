## 数据集摘要
本数据集为无人机航拍林业树种目标检测数据集，总计18718张640×640影像，支持YOLO、VOC、COCO三种标注格式，分为训练、验证、测试子集。数据集包含红松、白桦、杨树、核桃楸、水曲柳、落叶松、松树、其他树种共8类林木目标，标注量大，适合森林树种识别、林业资源智能调查、遥感林木检测模型训练与相关课题实验。
